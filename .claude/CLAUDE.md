# Project Rules

- **DO NOT use `uv` or `uv run`**. The project runs in an active Anaconda environment.
- Run Python commands directly using standard commands (e.g., `python script.py`, `pytest`).
- use `make test` to run tests.
- use `make update_translate` to update translation files (`.ts` and `.qm`).
- use `make lint` to check formatting, linting, and translations.
- use `make format` to auto-fix formatting.
